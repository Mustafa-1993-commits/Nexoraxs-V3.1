# Full Repository Discovery

This Claude-compatible skill is intentionally kept semantically identical to `.codex/skills/full-repository-discovery/SKILL.md`.

Before execution, read and follow:

- `.codex/skills/full-repository-discovery/SKILL.md`
- `docs/09-reference-intelligence/REGISTRY.md`
- `docs/09-reference-intelligence/contracts/`

Treat the source repository as read-only. Discover the repository as a complete system, extract every evidence-backed feature, generate the required Markdown and YAML artifacts, and enforce the same completion, evidence, lifecycle, licensing, change-detection, and authority rules defined by the canonical Codex skill.

Do not select features, recommend adoption, copy source code, modify the source repository, or implement NexoraXS runtime code.
