## Completion Decision

A repository may be marked `Complete` only when:

- every mandatory applicable area is `Pass`;
- every verified feature has exact source evidence;
- missing feature classes are justified as not applicable or resolved;
- dependency mapping is complete enough to understand feature boundaries;
- license impact is reviewed;
- unknowns and contradictions are explicit;
- pinned and current SHAs match, or delta discovery has resolved all affected knowledge.
