# hr-next Data Model

## Persistence Model

Frappe DocType JSON is the authoritative repository schema input. The pinned tree contains **159 DocTypes**: **105 parent/single documents** and **54 child tables**, split between **116 HR** and **43 Payroll** records. Frappe supplies physical schema generation, row persistence, generic CRUD, document naming, sharing, and site isolation.

## External Masters

Employee, User, Company, Department, Branch, Designation, Timesheet, Project, Task, accounting records, File, Workflow, Social Login Key, and several loan/fleet records are Frappe/ERPNext-owned. HRMS adds fields, scripts, overrides, links, events, and permission-aware uses; it does not redefine those canonical DocTypes here.

## Storage and State

- Local Compose: persistent MariaDB 10.8 volume and Redis service.
- Frappe cache: payroll and holiday lookups; PWA uses resource cache keys.
- Files: Frappe File records with public/private flag and parent attachment.
- Realtime: cache-key invalidation, salary-slip refresh, and employee updates.
- No repository-owned object-store provider, retention policy, backup plan, row-level tenant key, or production topology is present.
