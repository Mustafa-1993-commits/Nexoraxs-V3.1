## Route Boundaries and Gaps

- [proxy matcher](https://github.com/Kiranism/next-shadcn-dashboard-starter/blob/06e83c0b0e937f98184b343b92756ae0cadd7c92/src/proxy.ts) runs Clerk middleware for non-static requests and APIs but calls
  `auth.protect()` only for `/dashboard(.*)`.
- The dashboard metadata is `noindex, nofollow`; public static crawler policy lives in
  [robots.txt](https://github.com/Kiranism/next-shadcn-dashboard-starter/blob/06e83c0b0e937f98184b343b92756ae0cadd7c92/public/robots.txt).
- No custom forgot-password, reset-password, MFA, session-management, API documentation, health, audit, export,
  webhook, or realtime route is implemented. Clerk may expose provider-owned account flows inside its mounted
  components, but those are not claimed as repository behavior.
